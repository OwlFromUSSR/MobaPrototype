# MOBA Prototype

Учебный прототип игры в жанре **MOBA** на Unity **6000.0.29**.
Одна игровая сессия от старта до завершения: матч заканчивается разрушением базы, затем экран итогов со статистикой.

## Запуск

1. Установите Unity **6000.0.29** через Unity Hub и откройте папку проекта.
2. Дождитесь импорта пакетов (AI Navigation, Input System).
3. В меню выберите **MOBA → Build Prototype Scene**. Скрипт создаст сцену `Assets/Scenes/Main.unity`,
   материалы, префабы, конфиги и запечёт NavMesh.
4. Нажмите **Play**.

> Повторный запуск билдера пересоздаёт папку `Assets/Generated` и сцену. Балансные правки
> делайте в ScriptableObject-ах (`Assets/Generated/Configs`) уже после финальной генерации.

## Управление

| Действие | Клавиша |
|---|---|
| Идти / атаковать врага | ПКМ по земле / по врагу |
| Q — Bolt (скиллшот) | Q |
| W — Dash (рывок к курсору) | W |
| E — Shock (волна урона и замедления) | E |
| Пауза | P |
| Перезапуск после матча | R или кнопка |

Стоя на месте, герой сам атакует врагов в радиусе атаки.

## Правила матча

- Две команды: **Blue** (игрок) и **Red** (бот-герой). У каждой: база, башня, фонтан, волны миньонов.
- Миньоны спавнятся волнами и идут по линии; размер волны растёт со временем.
- Башня бьёт миньонов в первую очередь, затем героев, поэтому героям выгодно толкать башни вместе с миньонами.
- **Победа:** разрушить вражескую базу.
- **Фонтан** у базы лечит героя и восполняет ману. После смерти герой возрождается у фонтана через 8 секунд.
- **Экран итогов:** победитель, время матча, убийства героев, миньонов и зданий, нанесённый урон по командам, личная статистика игрока.

## Архитектура

```
Assets/
  Scripts/
    Core/       Unit, Health, UnitConfig, TargetFinder, MatchController, GameInput, TopDownCamera
    Units/      Mover (NavMeshAgent), StatusEffects, Fountain, HeroRespawn, MinionSpawner
    Combat/     Combat (атака), Projectile (снаряды)
    AI/         PlayerHero, BotHero (FSM), MinionAI, TowerAI
    Abilities/  AbilityData, HeroAbilities, TimedFx
    UI/         HealthBar, MatchHud (IMGUI)
  Editor/       MobaSceneBuilder — генерация сцены одной кнопкой
```

Основные решения:

- **Композиция вместо наследования:** юнит собирается из небольших компонентов (`Unit`, `Health`, `Mover`, `Combat` + AI).
- **События:** `Health.Damaged/Died` → `Unit.UnitDied/UnitDamaged` → `MatchController` считает статистику; HP-бары, фонтан и HUD не зависят друг от друга.
- **Данные в ScriptableObject:** `UnitConfig` и `AbilityData` позволяют менять баланс без правки кода.
- **Поиск целей** идёт по реестру `Unit.All` без слоёв и физических запросов.
- **Ввод** через `GameInput` работает с обоими вариантами Active Input Handling.
- **Бот** (состояния Lane / Retreat): идёт по линии, сражается, отступает при HP < 30%, не лезет под вражескую башню без поддержки миньонов.
- **UI** на IMGUI: не требует Canvas, шрифтов и TMP Essentials.

## Дополнительное задание

- Три способности героя: скиллшот, рывок, АоЕ-волна с замедлением (мана, перезарядки, HUD).
- Лечение и восполнение маны около базы (фонтан).
- Респавн героя, поведение бота при низком здоровье.

## История разработки

Коммиты отражают этапы: каркас проекта → ядро (юниты, здоровье, цели) → движение и камера →
бой и снаряды → цикл матча → способности → башни и фонтан → миньоны → герои (игрок, бот) → HUD и итоги →
генератор сцены.
